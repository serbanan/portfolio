## Project pages and search indexing

Each project shown on the homepage has a standalone page under `projects/`. Keep the project title, year, description, gallery alt text, and page URL consistent between the homepage entry and its project page. Add new project URLs to `sitemap.xml` when adding a page.

The site is published on GitHub Pages at `https://andreiserbahn.com/`. After publishing SEO changes, verify the domain in Google Search Console and submit `https://andreiserbahn.com/sitemap.xml` for indexing.
